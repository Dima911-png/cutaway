# Cutaway on iPhone — quick start

This guide is for using Cutaway from an iPhone without a computer.

## Start editing now

1. Open Safari and visit https://cutaway-one.vercel.app
2. Tap the Share button and choose **Add to Home Screen** if that option is available. This is only a shortcut; it does not install a native iPhone app.
3. Import a short test video from Photos or Files.
4. Try a vertical 9:16 project, then add a caption and choose the MrBeast-style preset if it is available in the current build.
5. Export a short test clip before editing a long video. Browser memory, WebGPU/WebAssembly support, and available device storage can affect performance.

## Important limits

- The public demo is the quickest way to try Cutaway. Creating this GitHub fork does **not** automatically publish a separate copy of the app.
- This project is a browser-based editor, not an iOS App Store application.
- On-device transcription and video export can be demanding on an iPhone. If Safari reloads, freezes, or export fails, try a shorter 10–20 second clip, close other tabs, and retry.
- The editor is open-source and has no required paid AI API key for its core local editing/transcription features. This does not guarantee unlimited device memory, storage, speed, or hosting.
- To publish a separately hosted version of this fork, configure a hosting provider such as Vercel and connect the repository. A provider account or deployment authorization may be required; GitHub alone does not automatically create a live hosted app.
